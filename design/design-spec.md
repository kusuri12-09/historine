# 디자인 명세

## 컬러

| 용도 | 색상 |
| --- | --- |
| 배경 | `#121212` |
| 기본 글자 | `#E5E5E5` |
| 메인 컬러 | `#7298C7` |
| 사이드 컬러 | `#F4D990` |
| 패널 배경 | `#1B1B1B` |
| 구분선 | `#303030` |
| 보조 글자 | `#9CA3AF` |

## 글꼴

기본 글꼴은 `Pretendard`를 사용한다.

운영 환경에서 Pretendard를 불러오지 못하는 경우 시스템 sans-serif 글꼴을 fallback으로 사용한다.

## 레이아웃

- 전체 배경은 다크 톤으로 유지한다.
- 본문 컨테이너의 최대 너비는 `1220px`로 한다.
- 헤더는 상단 고정형으로 제공하며, 현재 페이지 메뉴는 메인 컬러 배경으로 강조한다.
- 푸터는 하단 구분선과 함께 브랜드명을 간결하게 표시한다.

## 페이지 구성

### 연표

- 상단에는 영문 eyebrow, 제목, 설명을 배치한다.
- 본문 왼쪽에는 사건 설명을 세로로 나열한다.
- 본문 오른쪽에는 연도 노드를 세로 타임라인 형태로 표시한다.
- 연도 노드는 메인 컬러를 사용한다.

### 백과 리스트

- 카드 그리드는 데스크톱 기준 3열로 제공한다.
- 카드 상단에는 메인 컬러 또는 사이드 컬러 보더를 사용해 구분감을 준다.
- 카드에는 제목, 기간, 분류 배지, 요약, 태그를 표시한다.

### 백과 상세

- 상단 상세 카드에는 대표 이니셜, 제목, 기간, 분류를 표시한다.
- 본문은 상세 설명 영역과 태그/한줄 소개 사이드 영역으로 나눈다.
- 인물 상세는 사이드 컬러를 강조색으로 사용한다.
- 사건 상세는 메인 컬러를 강조색으로 사용한다.

## 컴포넌트 사용 기준

- 레이아웃과 시각 스타일은 Tailwind CSS 유틸리티 클래스를 기본으로 작성한다.
- 내비게이션은 Radix UI NavigationMenu를 사용한다.
- 태그, 분류 배지, 버튼 등 상태 표현이 필요한 작은 UI는 Material UI 컴포넌트를 사용한다.
