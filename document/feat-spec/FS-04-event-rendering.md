# Event 렌더링 기능 명세

## 개요

사용자는 `사건 백과` 페이지에서 역사적 사건을 하나씩 읽어볼 수 있어야 한다.

각 사건 페이지에는 사건의 제목과 역사적 사건에 대한 내용이 서술된다.

---

## 화면 구성

| 요소 | 설명 |
| --- | --- |
| 페이지 이름 | 사건 백과 |
| 제목 | 역사적 사건의 문서 제목 |
| 본문 | 사건에 대한 설명 |

---

## 조회 예시

```http
GET /events/{id}
```

응답 데이터 예시:

```json
{
  "id": 1,
  "title": "임진왜란",
  "content": "1592년부터 1598년까지 조선과 일본 사이에 벌어진 전쟁이다."
}
```

---

## 렌더링 정책

본문은 저장된 콘텐츠를 읽기 좋은 형태로 렌더링한다.

마크다운 콘텐츠가 사용되는 경우 마크다운 렌더링 정책을 따른다.
