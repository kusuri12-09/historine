# Person 렌더링 기능 명세

## 개요

사용자는 `인물 백과` 페이지에서 역사적 인물을 하나씩 읽어볼 수 있어야 한다.

각 인물 페이지에는 인물의 이름 또는 제목과 역사적 설명이 서술된다.

---

## 화면 구성

| 요소 | 설명 |
| --- | --- |
| 페이지 이름 | 인물 백과 |
| 제목 | 역사적 인물의 이름 또는 문서 제목 |
| 본문 | 인물에 대한 설명 |

---

## 조회 예시

```http
GET /persons/{id}
```

응답 데이터 예시:

```json
{
  "id": 1,
  "title": "세종대왕",
  "content": "조선의 제4대 국왕으로 훈민정음을 창제하였다."
}
```

---

## 렌더링 정책

본문은 저장된 콘텐츠를 읽기 좋은 형태로 렌더링한다.

마크다운 콘텐츠가 사용되는 경우 마크다운 렌더링 정책을 따른다.
