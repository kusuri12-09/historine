# Timeline 렌더링 기능 명세

## 개요

사용자는 역사 연표를 한 줄 형태로 볼 수 있어야 한다.

연표는 시간 순서대로 렌더링되며, 사용자는 스크롤을 통해 전체 연표를 이어서 탐색할 수 있다.

---

## 화면 구성

| 요소 | 설명 |
| --- | --- |
| 연표 라인 | 전체 연표의 흐름을 나타내는 한 줄 |
| 연도 | 각 항목의 기준 연도 |
| 내용 | 해당 연도에 대한 설명 |

---

## 정렬 기준

기본 정렬은 오래된 연도에서 최신 연도 순으로 한다.

```sql
SELECT id, year, content
FROM timeline
ORDER BY year ASC;
```

---

## 빈 상태

등록된 연표가 없으면 빈 상태 메시지를 표시한다.

예시:

```text
등록된 연표가 없습니다.
```
