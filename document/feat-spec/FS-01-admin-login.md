# 관리자 로그인 기능 명세

## 개요

관리자 로그인은 콘텐츠 등록, 수정, 삭제 권한을 구분하기 위한 기능이다.

일반 사용자 화면에는 로그인 UI를 제공하지 않고, 관리자는 관리자 전용 API로만 인증한다.

---

## 사용자 구분

### 비로그인 사용자

비로그인 사용자는 공개 콘텐츠만 조회할 수 있다.

조회 가능한 콘텐츠는 연표, 인물 백과, 사건 백과이다.

### 관리자

관리자는 로그인 후 콘텐츠를 관리할 수 있다.

관리 가능한 콘텐츠는 연표, 인물, 사건 데이터이다.

---

## 로그인 방법

관리자는 아이디와 비밀번호를 관리자 로그인 API로 전달한다.

```http
POST /api/admin/auth/login
```

요청 데이터 예시:

```json
{
  "username": "admin",
  "password": "password"
}
```

로그인에 성공하면 서버는 관리자 세션을 생성한다.

---

## 인증 유지 방식

초기 구현은 세션 쿠키 방식을 사용한다.

관리자 로그인 성공 후 서버는 세션을 생성하고, 클라이언트는 세션 쿠키를 통해 인증 상태를 유지한다.

관리자 기능 요청 시 서버는 세션에 관리자 인증 정보가 있는지 확인한다.

예시:

```http
POST /api/admin/timelines
Cookie: JSESSIONID=...
```

---

## 로그아웃

관리자는 로그아웃 API를 호출해 관리자 세션을 종료한다.

```http
POST /api/admin/auth/logout
```

로그아웃 후 기존 세션으로는 관리자 기능을 사용할 수 없다.

---

## 접근 제어

| 사용자 상태 | 허용 기능 |
| --- | --- |
| 비로그인 사용자 | 연표 조회, 인물 백과 조회, 사건 백과 조회 |
| 관리자 | 연표 등록/수정/삭제, 인물 등록/수정/삭제, 사건 등록/수정/삭제 |

관리자 기능은 서버에서 인증 여부를 검증해야 한다.

---

## 예외 처리

- 인증되지 않은 사용자가 관리자 기능에 접근하면 접근을 차단한다.
- 로그인 실패 시 어떤 값이 틀렸는지 구체적으로 알려주지 않는다.
- 로그아웃 이후 기존 인증 정보로 관리자 기능을 사용할 수 없어야 한다.
