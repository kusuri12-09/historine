# Auth 요구사항

## 1. 로그인 제공 방식

- 관리자 로그인은 일반 사용자 UI로 제공하지 않고, 관리자 전용 API로만 제공해야 한다.
- 일반 사용자 화면에는 로그인 버튼, 로그인 페이지 링크, 회원가입 기능을 노출하지 않아야 한다.

---

## 2. 로그인 처리

- 관리자는 아이디와 비밀번호로 로그인할 수 있어야 한다.
- 로그인 성공 시 서버는 관리자 세션을 생성해야 한다.
- 로그인 실패 시 어떤 인증 값이 틀렸는지 구체적으로 노출하지 않아야 한다.

---

## 3. 인증 유지

- 초기 구현은 세션 쿠키 기반 인증 방식을 사용해야 한다.
- 관리자 기능 요청 시 서버는 세션에 관리자 인증 정보가 있는지 검증해야 한다.

---

## 4. 로그아웃

- 관리자는 로그아웃할 수 있어야 한다.
- 로그아웃 시 서버는 관리자 세션을 만료시켜야 한다.
- 로그아웃 이후 기존 인증 정보로 관리자 기능을 사용할 수 없어야 한다.

---

## 5. 접근 제어

- 비로그인 사용자는 공개 조회 기능만 사용할 수 있어야 한다.
- 데이터 등록, 수정, 삭제 기능은 관리자만 사용할 수 있어야 한다.
