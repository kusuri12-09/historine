# Request Feedback 요구사항

## 1. 요청 상태 안내

- 사용자가 관리자 기능에서 등록, 수정, 삭제 요청을 실행하면 즉시 요청 상태를 안내해야 한다.
- 요청 시작 시 처리 중임을 알 수 있는 메시지를 표시해야 한다.
- 요청 성공 시 반영이 완료되었음을 알 수 있는 메시지를 표시해야 한다.
- 요청 실패 시 실패 사실과 다시 시도할 수 있음을 알 수 있는 메시지를 표시해야 한다.
- 안내 메시지는 브라우저 기본 `alert`에만 의존하지 않고 화면 안에서 확인할 수 있어야 한다.

---

## 2. 요청 중 버튼 상태

- 요청이 진행 중인 동안 동일 작업 버튼은 비활성화해야 한다.
- 요청이 진행 중인 동안 버튼 문구 또는 시각 상태를 변경해 사용자가 대기 상태를 인지할 수 있어야 한다.
- 버튼 비활성화는 동일 요청의 중복 호출을 방지해야 한다.
- 요청이 완료되면 버튼은 다시 사용할 수 있는 상태로 돌아와야 한다.

---

## 3. 적용 범위

- 초기 적용 범위는 관리자 등록, 수정, 삭제 기능으로 한다.
- 연표, 인물 백과, 사건 백과의 관리자 요청은 동일한 피드백 정책을 따라야 한다.
- 공개 조회 페이지의 일반 탐색에는 본 요구사항을 적용하지 않는다.
